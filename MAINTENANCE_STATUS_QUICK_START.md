# Maintenance Service Status - Quick Start Guide

## For Admins

### How to Update Maintenance Service Status

1. **Log in to Admin Dashboard**
   - Go to admin panel
   - Log in with admin credentials

2. **Find the Maintenance Service**
   - Go to Dashboard
   - Scroll to "Upcoming Tasks" section
   - Look for maintenance services (Grave Painting, Grave Cleaning, Grave Restoration)
   - Search by customer name or service name if needed

3. **Click the Status Button**
   - In the "Actions" column, click the green "Status" button
   - Service Completion Modal will open

4. **Update the Status**
   - Select one of three options:
     - **Pending**: Service not started yet
     - **Ongoing**: Service is in progress
     - **Done**: Service is completed

5. **Upload Photos (if status = Done)**
   - Click the upload area or drag and drop images
   - Upload at least one photo as proof of completion
   - You can upload multiple photos
   - Remove photos by clicking the X button if needed

6. **Save Changes**
   - Click "Update Status" button
   - Wait for success message
   - Modal will close automatically

### Status Options Explained

| Status | Meaning | Photos Required |
|--------|---------|-----------------|
| Pending | Service hasn't started | No |
| Ongoing | Service is in progress | No |
| Done | Service is completed | Yes (at least 1) |

## For Clients

### How to View Maintenance Service Status

1. **Log in to Client App**
   - Go to client app
   - Log in with your account

2. **Go to My Requests**
   - Click on your profile icon (top right)
   - Select "My Requests" from dropdown menu

3. **Find Your Maintenance Service**
   - Look for your maintenance service (e.g., "Grave Painting")
   - You'll see a status badge next to it

4. **Check the Status**
   - **Green badge** = Completed ✓
   - **Orange badge** = In Progress ⏳
   - **Gray badge** = Pending ⏱️

5. **View Completion Photos**
   - If status is "Completed", you'll see photo thumbnails
   - Click on any photo to view it in full size
   - Use arrow keys or buttons to navigate between photos

## Common Tasks

### As Admin

**Task**: Mark a grave painting service as completed
1. Find the booking in Upcoming Tasks
2. Click "Status" button
3. Select "Done"
4. Upload before/after photos
5. Click "Update Status"
6. ✓ Done!

**Task**: Update service to "In Progress"
1. Find the booking in Upcoming Tasks
2. Click "Status" button
3. Select "Ongoing"
4. Click "Update Status"
5. ✓ Done!

### As Client

**Task**: Check if my grave painting is done
1. Go to "My Requests"
2. Find "Grave Painting" service
3. Look at the status badge
4. If green, click photos to see the work done
5. ✓ Done!

## Tips & Tricks

### For Admins
- Use the search bar to quickly find services by customer name
- Upload clear, high-quality photos as proof of completion
- You can update status multiple times (e.g., Pending → Ongoing → Done)
- Photos are stored and shown to clients immediately

### For Clients
- Check "My Requests" regularly to see service progress
- Photos are only visible when status is "Completed"
- You can view photos in full size by clicking on them
- Contact support if you don't see your service

## Troubleshooting

### Status button not showing?
- Make sure it's a maintenance service (Grave Painting, Cleaning, or Restoration)
- Refresh the page
- Clear browser cache

### Can't upload photos?
- Check file size (max 10MB)
- Use PNG, JPG, or GIF format
- Try a different browser

### Photos not showing on client side?
- Make sure status is set to "Done"
- Refresh the page
- Check if photos were uploaded successfully
