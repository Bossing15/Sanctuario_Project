# Sanctuario - Simple Screenshot Guide

## Quick URLs

### Public Pages
- Home: `http://localhost:3000/`
- Services: `http://localhost:3000/services`
- Lawn Lots: `http://localhost:3000/lawn-lots`
- Contact: `http://localhost:3000/contact`

### Authentication
- Login: `http://localhost:3000/login`
- Sign Up: `http://localhost:3000/signup`

### Client Dashboard (After Login)
- Dashboard: `http://localhost:3000/dashboard`
- My Reservations: `http://localhost:3000/my-reservations`
- My Services: `http://localhost:3000/my-services`
- Payments: `http://localhost:3000/payments`
- Profile: `http://localhost:3000/profile`

### Admin (API Endpoints)
- Admin Login: `POST /api/admin/login`
- Users: `GET /api/users`
- Payments: `GET /api/payments`
- Bookings: `GET /api/bookings`
- Services: `GET /api/services`
